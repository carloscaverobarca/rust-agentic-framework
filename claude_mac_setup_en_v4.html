🔐 Setting Up Claude Code Securely

Complete guide: Mac Account vs Dev Container (VSCode/IntelliJ)

?
Which option should you choose?

You have 2 main options:

🐳 Dev Container (RECOMMENDED)

Advantages:

  • Complete isolation (true sandbox)
  • Easy to reset if something goes wrong
  • Doesn't affect your system
  • Portable across projects
  • Works with VSCode and IntelliJ

Disadvantages:

  • Requires Docker installed
  • Uses more resources (RAM/CPU)

👤 Separate Mac Account

Advantages:

  • Doesn't require Docker
  • Faster (native)
  • Fewer resources
  • Simple to configure
  • Works with any IDE

Disadvantages:

  • Less isolation
  • Shares system with your account
  • Harder to reset
💡 My recommendation: If you have Docker and VSCode, use Dev Container. It's safer and more professional. If you prefer something simpler and lighter, use the separate account.
🤖 Bonus: GitHub Copilot
This guide focuses on Claude Code, but you can use GitHub Copilot simultaneously. Both tools work in Dev Containers and separate accounts. Copilot excels at real-time autocompletion, while Claude Code shines in deep analysis and refactoring.

OPTION A: Dev Container with VSCode or IntelliJ 🐳

1
Install Docker Desktop and configure your IDE

Step 1: Install Docker Desktop

  • Download Docker Desktop from docker.com
  • Install and open Docker Desktop
  • Verify it works:
docker --version # Should display: Docker version 24.x.x

Step 2A: For VSCode

  • Open VSCode
  • Go to Extensions (⌘+Shift+X)
  • Search and install: "Dev Containers" (by Microsoft)
  • Optional: Install "GitHub Copilot" for real-time AI assistance

Step 2B: For IntelliJ IDEA

  • Make sure you have IntelliJ IDEA Ultimate (Community edition doesn't support Dev Containers)
  • Go to Settings/Preferences → Plugins
  • Search and install: "Dev Containers" (by JetBrains)
  • Optional: Install "GitHub Copilot" for real-time AI assistance
  • Restart IntelliJ if necessary
💡 Note about IntelliJ: Dev Containers support requires IntelliJ IDEA Ultimate (paid version). If you have Community Edition, use VSCode or the separate account option.
2
Create Dev Container configuration

In your repository, create the .devcontainer folder with configuration:

# From your project root mkdir -p .devcontainer cd .devcontainer

Choose the example based on your language:

📦 Node.js / JavaScript / TypeScript

Create .devcontainer/devcontainer.json:

3
Open the project in the container

For VSCode:

  • Open your project in VSCode
  • Press ⌘+Shift+P
  • Type: Dev Containers: Reopen in Container
  • VSCode will restart inside the container

For IntelliJ IDEA:

  • Open your project in IntelliJ
  • Go to File → Remote Development → Dev Containers
  • Select "Create Dev Container and mount sources"
  • Choose the configuration from .devcontainer/devcontainer.json
  • IntelliJ will build the container and open a new connected window

Or from terminal (for both):

cd ~/your-project # For VSCode code . # Then ⌘+Shift+P → "Reopen in Container" # For IntelliJ idea . # Then File → Remote Development → Dev Containers
⚠️ The first time will take a few minutes to download the Docker image.
4
Install Claude Code inside the container

Now that you're inside the container, install Claude Code:

# Inside the Dev Container npm install -g @anthropic-ai/claude-code # Configure your API key claude-code config set api-key YOUR_API_KEY_HERE # Verify installation claude-code --version
💡 Container advantage: Everything Claude does will be isolated inside the container. Your Mac system stays completely protected.
5
Test and use Claude Code

Ready! Now you can use Claude Code securely:

# From integrated terminal (inside container) # Works the same in VSCode or IntelliJ claude-code "Analyze this code and suggest improvements" # Or start an interactive session claude-code chat

Dev Container benefits:

  • ✅ Claude can read and write files inside the container
  • ✅ Complete isolation from host system
  • ✅ If something goes wrong, just delete the container and recreate it
  • ✅ Same environment on any machine (portable)
  • ✅ Works with VSCode and IntelliJ IDEA Ultimate
  • ✅ Compatible with GitHub Copilot for better productivity
🚀 Combine Claude Code + GitHub Copilot:
Use GitHub Copilot while coding for quick code suggestions, and Claude Code for more complex tasks like refactoring, architecture analysis, or detailed explanations. Both tools complement each other perfectly!
# Example workflow: # 1. Copilot helps you write code fast # 2. Claude Code reviews and optimizes the entire file claude-code "Review this file and suggest performance and maintainability improvements"
🔄 Reset the container:
VSCode: ⌘+Shift+P → "Dev Containers: Rebuild Container"
IntelliJ: File → Remote Development → Dev Containers → Rebuild Container

OPTION B: Separate Mac Account 👤

1
Create a new user account

Option 1: Using the GUI

  • Open System Settings → Users & Groups
  • Click the lock 🔒 and authenticate
  • Click the + button to add a user
  • Select type: "Standard"
  • Name: claude-dev
  • Set a strong password

Option 2: Using terminal

# Create the claude-dev user sudo dscl . -create /Users/claude-dev sudo dscl . -create /Users/claude-dev UserShell /bin/zsh sudo dscl . -create /Users/claude-dev RealName "Claude Development" sudo dscl . -create /Users/claude-dev UniqueID 503 sudo dscl . -create /Users/claude-dev PrimaryGroupID 20 sudo dscl . -create /Users/claude-dev NFSHomeDirectory /Users/claude-dev sudo dscl . -passwd /Users/claude-dev YOUR_PASSWORD sudo createhomedir -c -u claude-dev
2
Configure read/write permissions

Now let's give read and write access to your repositories:

Method 1: Use shared group (RECOMMENDED)

# Create a group to share repos sudo dseditgroup -o create -r "Development Group" devgroup # Add your user and claude-dev to the group sudo dseditgroup -o edit -a $(whoami) -t user devgroup sudo dseditgroup -o edit -a claude-dev -t user devgroup # Change the group of your repositories cd ~/Projects # or wherever your repos are sudo chgrp -R devgroup . # Give read/write permissions to the group sudo chmod -R g+rw .

Method 2: ACL (Access Control Lists)

# For a specific repo cd ~/Projects/my-repo # Give full read/write permissions to claude-dev sudo chmod +a "claude-dev allow read,write,execute,delete,append,readattr,writeattr,readextattr,writeextattr" . # Apply recursively find . -type d -exec sudo chmod +a "claude-dev allow read,write,execute,delete,append,readattr,writeattr,readextattr,writeextattr" {} \;
⚠️ Important: With these permissions, claude-dev can READ, WRITE and MODIFY files in your repositories. Make sure to use version control (Git) to be able to revert changes.
💡 Verify permissions:
# View file permissions ls -le file.js # Should show: claude-dev allow read,write,...
3
Install Claude Code in claude-dev account

Switch to the claude-dev account to install Claude Code:

# Switch to claude-dev account su - claude-dev # Or log out and log in with claude-dev from the login screen

Once in the claude-dev account, install Claude Code:

# Install Claude Code npm install -g @anthropic-ai/claude-code # Or if using another package manager # brew install claude-code
4
Configure and test

Configure Claude Code and verify permissions:

# Configure your Anthropic API key claude-code config set api-key YOUR_API_KEY_HERE # Navigate to a repository cd ~/Projects/my-project # adjust path # Verify you can read ls -la # ✅ Should work cat file.js # ✅ Should work # Verify you can write echo "// Test" >> test.js # ✅ Should work rm test.js # ✅ Should work
💡 Security verification: If you can create, modify and delete files, perfect! Permissions are correctly configured. Always remember to commit to Git before letting Claude work.
5
Additional security improvements (Optional)

Limit other system access:

  • Disable sudo access: The claude-dev account shouldn't have admin privileges
  • Use Git: ALWAYS commit before letting Claude work
  • Review changes: Use git diff after Claude works
  • Monitor activity: Review logs regularly
# Verify claude-dev is NOT in admin groups groups claude-dev # Shouldn't show 'admin' or 'wheel' # Useful script to switch to claude-dev easily echo "alias claude-dev='su - claude-dev'" >> ~/.zshrc source ~/.zshrc # Recommended workflow with Git git add . git commit -m "Before Claude work" # Now let Claude work # Then review: git diff git status
🔒 Security reminder: Never share your Anthropic API key. Keep it secure in environment variables or a password manager. With write permissions, Claude can modify files, so ALWAYS use Git to be able to revert changes.
🎉 Done! Now you have Claude Code securely configured.

What did you choose?

  • Dev Container: Maximum isolation, easy to reset, perfect for experimenting. Claude can write without affecting your system.
  • Mac Account: Faster and lighter. Claude can read/write in your repos. Remember to always use Git!

💡 Pro tip: Combine both options - use Dev Container for experimentation and Mac account for stable work.
